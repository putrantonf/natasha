# For Natasha

Perjalanan ulang tahun interaktif dalam ilustrasi fantasi, dibuat untuk Natasha.

Situs statis: HTML, CSS dan JavaScript native. Tidak membutuhkan build, akun pengunjung, CDN, atau layanan API. Semua art runtime berada di assets/. Foto referensi mentah tidak disertakan.

GitHub Pages dapat diterbitkan dari branch main, folder root. Berkas .nojekyll mempertahankan runtime statis ini tanpa proses Jekyll.
